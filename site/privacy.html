This page describes ClipShelf public beta 0.1.0 and its download website.

What the app collects

After you choose Start Recording, ClipShelf reads copied plain text while it is running and retains up to 200 items, up to 100 KB per item. Entries include the copied text and a timestamp. It does not collect images or files.

Where it is stored

The app saves history locally at ~/Library/Application Support/ClipShelfPublic/history.json. The JSON file uses owner-only file permissions. It is not encrypted by the app. Device backups may include this file, depending on your backup settings.

No app uploads or analytics

ClipShelf contains no network calls, advertising, account system, analytics or remote crash reporting. Its clipboard data is not uploaded by the app.

Sensitive text

ClipShelf skips recognized confidential and transient pasteboard types. These markers depend on the source app. Ordinary copied passwords, financial details, messages and other private text may still be recorded. Pause recording before copying anything you do not want retained.

Your controls

Right-click the menu bar icon to pause or resume recording, clear history, or quit. Clearing history removes ClipShelf’s saved entries, but leaves the current system clipboard unchanged. To remove stored data when uninstalling, delete the ClipShelfPublic folder above. Backups are managed separately by you.

The website

This website is hosted on Vercel. Downloads and source code are hosted on GitHub. This website adds no analytics scripts, ads, account forms or tracking cookies. The hosting provider may process ordinary technical request information, such as your IP address and requested file, to deliver and protect the site. The copy-command button writes only the displayed installation command to your clipboard; it does not read your existing clipboard.
